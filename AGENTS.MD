# Frontend

Sempre que estiver trabalhando na interface:

- Consulte o MCP do Magic UI antes de criar componentes visuais do zero.
- Prefira componentes existentes do Magic UI quando forem adequados.
- Consulte o MCP para confirmar APIs, propriedades e instalação.
- Não invente componentes ou propriedades do Magic UI.
- Adapte os componentes ao design existente do projeto.
- Mantenha compatibilidade com Next.js, React, Tailwind CSS e shadcn/ui.
